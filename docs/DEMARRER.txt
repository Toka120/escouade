ESCOUADE 1.6.1 — VERSION DE TEST LOCALE

Lancer Escouade.exe dans ce dossier. Garder resources.neu, Organisateur Escouade.exe et Capture Escouade.exe à côté.
Si Escouade était ouverte pendant la livraison, la fermer puis la rouvrir.

RACCOURCIS BUREAU ET RECHERCHE WINDOWS
Double-cliquer une fois sur « Creer les raccourcis Escouade.cmd » : Escouade apparaît sur le Bureau
et dans le menu Démarrer (taper « Escouade » dans la recherche). Les raccourcis démarrent Escouade
dans ce dossier, donc avec tes sauvegardes. Garder ce dossier au même endroit ; si tu le déplaces,
relance le script. « Retirer les raccourcis Escouade.cmd » les enlève. Aucune donnée n'est modifiée.

Ce dossier contient :
- Escouade.exe, resources.neu, Organisateur Escouade.exe, Capture Escouade.exe : application Windows 1.6.1.
- Creer les raccourcis Escouade.cmd, Retirer les raccourcis Escouade.cmd, Raccourcis-Escouade.ps1, Escouade.ico : raccourcis.
- Escouade-1.6.1-Windows.zip : paquet portable complet.
- PATCHNOTES-1.6.1.md et PATCHNOTES-1.6.0.md : changements et tests réellement effectués.
- UTILISER-LE-SCAN.md : lire le panneau Caractéristiques de Dofus.
- resultats-tests.json, resultats-scan.json, resultats-banque.json, resultats-services.json : vérifications automatiques.
- Sources Escouade : code, outils de construction et tests (aussi sur GitHub, branche dev/1.6.0, mise à jour en 1.6.1).
- Visuels : maquettes, captures de démonstration, éléments d'interface.
- Archives : anciens exécutables, ressources et paquets, conservés avant chaque remplacement.
- Publication future : brouillon de fiche produit (rien n'est soumis).

NOUVEAUTÉS 1.6.0
Scan et import : Escouade trouve seul le panneau Caractéristiques dans la capture et ignore le chat,
les quêtes et la carte. Toutes les valeurs du panneau sont lues : niveau, PV, Force, Intelligence,
Chance, Agilité, Sagesse, PA, PM, portée, critique, puissance, invocations, pods, prospection, tacle,
fuite, retraits, esquives, initiative, soins, renvoi, et le tableau dommages / résistances / résistances %
de chaque élément, critiques, poussée, sorts, armes, distance, mêlée. Vérifier puis enregistrer.
Diagrammes : radar des caractéristiques, barres par élément, évolution d'un relevé à l'autre.
Catalogue d'objets : effets, panoplies, recettes ; ajout aux crafts et « viser » dans le Stuff en un clic.
Carte DofusDB : carte interactive dans Escouade (Internet nécessaire), commande /travel à copier
et donjons de ton niveau.
Positions de donjons : toutes relues dans les guides Dofus pour les Noobs ; plus aucune « à confirmer ».

SAUVEGARDES
Les profils WebView2 existants dans .tmp sont conservés. Ne pas supprimer .tmp.
Dans Paramètres, exporter un JSON pour garder une copie indépendante. Ne pas lancer deux Escouade en même temps.
Les relevés et captures personnels (Releves Xolmora, Captures de scan) restent sur ce PC et ne sont jamais publiés.

LIMITES
La lecture du scan est très fiable sur le panneau Caractéristiques de Dofus 3 mais doit toujours être vérifiée.
Les positions sont vérifiées dans les guides, pas en jeu. Les prix HDV sont manuels.
La carte DofusDB, les recherches en ligne, l'Almanax et les indices de chasse nécessitent Internet.
Escouade n'effectue aucune action de jeu : l'organisateur et la capture ne font que choisir, afficher ou photographier une fenêtre.
La version publique n'a pas été remplacée : « Rechercher une mise à jour » peut afficher une version plus ancienne.
Application indépendante, non affiliée à Ankama.
