SAUVEGARDES
Les profils WebView2 existants dans .tmp sont conservés. Ne pas supprimer .tmp.
Une sauvegarde 1.1 est convertie au premier chargement ; sa copie d'origine est conservée.
Dans Paramètres, exporter un JSON pour garder une copie indépendante ou transférer les données.
Ne pas lancer plusieurs copies simultanées sur le même port.

La version publique n'a pas été remplacée : Rechercher une mise à jour peut donc indiquer que
la version locale 1.5.2 est déjà à jour alors que la version publique reste antérieure.

Les prix HDV sont manuels. Les données de jeu sont des références datées ; ouvrir les guides
pour les prérequis, les variantes et les positions indiquées comme incertaines.
Les recherches d'objets, nouvelles recettes, calendrier et indices nécessitent Internet.
Les fournisseurs reçoivent les termes, dates et coordonnées recherchés, mais pas la sauvegarde.
Les guides complets, itinéraires et catalogues éditoriaux restent accessibles sur les sites sources.

Le paquet n'est pas encore une version Microsoft Store : pas de MSIX certifié ni de signature
d'éditeur ajoutée. Voir Publication future pour la suite.

SCAN ET IMPORT 1.5.1
Ouvrir Scan et import. Capturer une fenêtre Dofus (outil Capture Escouade.exe), puis attendre le retour automatique de l’image dans Escouade. Si l’outil est lancé séparément, importer le PNG ou Ctrl+V hors d’un champ texte. Sélectionner la zone utile avec la souris puis Lire le texte localement. Le moteur français est embarqué et ne téléverse pas les images. Vérifier/corriger les valeurs avant Enregistrer. Les libellés « Force : 125 » peuvent être proposés automatiquement ; les textes ambigus restent à saisir.
Le nom doit correspondre au personnage actif. Une sauvegarde précède l’enregistrement. Le relevé conserve portefeuille, XP restante et ressources nommées sans remplacer le journal de kamas ni le stock partagé. Les icônes seules ne sont pas identifiées. Voir UTILISER-LE-SCAN.md.
Releves Xolmora contient le relevé personnel séparé des sources. Captures de scan contient les PNG privés, à ne pas joindre aux publications.
